# EduMoja v12

## Goal
Freeze feature tourism. Align product with street pricing and clear access.

## Pricing (per term, KES)
| Plan     | Price | Access summary                                      |
|----------|-------|-----------------------------------------------------|
| Free     | 0     | Dashboard, students, admissions, setup (limited)    |
| Starter  | 2,000 | + basic fees, exams (watermark, no export)          |
| Standard | 5,000 | + attendance, timetable, communications             |
| Full     | 9,000 | + CSV/PDF export, capitation, library, boarding     |

## Legacy plan ids in database
Still accepted: `basic` → starter, `premium` → standard, `pro`/`custom` → full.

## What we did not add
New modules, fleet GPS, biometrics, holding school fee money.
